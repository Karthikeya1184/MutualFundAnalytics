# Mutual Fund Analytics Platform

## Overview

The Mutual Fund Analytics Platform is an end-to-end analytics solution developed for Bluestock Fintech.

The project performs data ingestion, cleaning, transformation, performance analytics, advanced risk analysis, investor analytics, and dashboard reporting.

---

## Features

* ETL Pipeline
* SQLite Database Storage
* Mutual Fund Performance Analytics
* Alpha/Beta Analysis
* CAGR Analysis
* Sharpe Ratio Analysis
* Maximum Drawdown Analysis
* VaR & CVaR Risk Analysis
* HHI Sector Concentration Analysis
* SIP Continuity Analysis
* Investor Cohort Analysis
* Power BI Dashboard
